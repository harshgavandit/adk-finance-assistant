# Finance Assistant

A chat app for understanding personal finance, reviewing a sample budget, and working through savings goals.

[Open the app](https://adk-finance-assistant.vercel.app) — a private access code is required to chat.

## What it does

- Explains finance concepts such as recurring deposits, budgeting, and savings.
- Breaks down a sample monthly budget: ₹50,000 in income, ₹40,000 in expenses, and ₹10,000 in savings.
- Suggests spending changes to help work toward a savings target.
- Finds public sources for investment questions, including bank deposit rates.
- Uses earlier messages in the current chat to answer follow-up questions.

The budget figures are demo data. For current rates and prices, the app provides source links so you can check the values on the original websites.
